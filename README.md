# 👶 Pais de Primeira

Bem-vindo ao **Pais de Primeira**!

Este projeto foi criado para ajudar pais e mães de primeira viagem com informações confiáveis, organizadas e de fácil entendimento.

## 🌟 Recursos

- 🤰 Calculadora da Gravidez
- 👶 Desenvolvimento do Bebê
- 💉 Calendário de Vacinas
- 🍼 Alimentação
- 😴 Sono
- 🚑 Primeiros Socorros
- 📚 Artigos informativos

## 🎯 Objetivo

Oferecer um portal moderno, gratuito e acessível para apoiar famílias desde a gravidez até os primeiros anos de vida da criança.
